# Sounds

Every game sound is generated by `tools/sfx/make_sfx.py` (run it from the repo root) from short **CC0 1.0** recordings
(Kenney packs, the VCSL and VSCO 2 CE sample libraries and a few Freesound sounds) that we cut, layer and process
ourselves, plus noise risers and sine sub booms synthesised in `tools/sfx/cine.py`. The source clips are in
`tools/sfx/sources/`; `tools/sfx/sources.md` lists each one with its origin. `python3 tools/sfx/preview.py out.mp3`
strings the set together for a listen.

- Board sounds and the victory / defeat / draw stings: `<name>.mp3` (160 kbps, stereo), named as in `js/core/sound.js`
  (`move-self`, `move-opponent`, `capture`, `castle`, `move-check`, `promote`, `premove`, `illegal`, `notify`,
  `game-start`, `game-end`, `tenseconds`, `victory`, `defeat`, `draw`).
- `tick.wav`, `jumpscare.wav`, `explosion.wav`: shared effects (16-bit stereo).
- Mode-specific effects live in `assets/modes/<id>/<name>.wav`.

Style (v4): modern cinematic / premium game-UI sound design. Big moments (game start / end, results, achievements,
new rule page, portals, explosions...) get a riser or reverse whoosh into a crisp impact, a tuned sub boom and a warm
low string-pad tail. Frequent cues (moves, capture, castle, check, premove...) are 60-250 ms: a tight layered transient,
a subtle low thump and a tiny filtered air tail. Victory is bright and lifts, defeat is dark and sinks, draw is neutral.
No bells, chimes, dings, glass, chiptune or brass: `python3 tools/sfx/ring_check.py` flags any struck tonal ring over
150 ms. Mastered with a BS.1770 meter: frequent cues about -19 LUFS momentary-max, big moments about -15 LUFS
short-term max, in-play mode effects about -17, true peak at or below -1 dBTP.

`lichess/` holds the Lichess "piano" sound set (Enigmahack, AGPLv3+, from lichess-org/lila `public/sound/piano`).
It is no longer used by the game and is kept only for reference.
